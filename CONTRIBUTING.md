# Contributing

Contributions should improve the portable Listing workflow or make an evidence rule clearer. Include a small fictional example showing the decision changed by the proposal. Keep source type, date, marketplace, and data gaps visible in examples.

Do not submit private BizOS tools or prompts, credentials, customer data, copied competitor prose, scraped datasets without redistribution rights, or unverified platform-policy claims. Cite the current official platform rule when changing a compliance instruction. Avoid making BizOS MCP mandatory: the skill must remain useful with user material and permitted public research.
